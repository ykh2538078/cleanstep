CleanStep 画面設計仕様書

地域循環型エコシステム構築プロトタイプ（PoC仕様）
システム名称: 地域ごみ拾いポイントシステム
改訂日: 2026/09/08 | 提出区分: 最終成果物
設計思想: MVP（最小実用版）開発ポリシー準拠
【共通ドメイン設計】スマートフォン振り子や位置情報偽装（チート）によるインフレを防止するため、歩数・距離・消費カロリー等の健康データは活動実績の可視化にのみ利用し、ポイント計算ロジックからは厳密に除外する。
SCREEN 01

ログイン画面

画面説明利用者の識別、および個別データ（ポイント・活動履歴）を切り替えるための認証画面。
デモ動作条件プルダウンから王道デモ用の「テストユーザー（初期保有: 350 pt）」を選択した状態。
非機能の割り切り評価検証におけるユーザー切り替えの手間をゼロ化し、UI/UXの連動を最速でテストするため、意図的にパスワード入力を省いた簡易選択式を採用。
遷移・バックエンドログインボタン押下 ➔ 02 トップメニュー（初期状態）へ遷移。選択したIDをFlaskのセッション（`session['user_id']`）へ安全に保持。

SCREEN 02

トップメニュー（初期状態）

画面説明システムのメインダッシュボード。現在の保有ポイント、参加可能な5大地域イベント、活動・交換履歴を統合表示。
デモ動作条件ログイン直後の初期状態。データベースの初期シード値に基づき、保有ポイントは350 pt、履歴は初期ログのみをレンダリング。
UIコピーの最適化文言を「活動履歴」から「あなたの活動・交換履歴」へ変更。ポイントの獲得（インフロー）と消費（アウトフロー）を1つのタイムラインに一貫させる。
遷移・バックエンド「詳細・参加」リンク押下 ➔ 03 イベント詳細・参加（計測中）へ遷移。

SCREEN 03

イベント詳細・参加（計測中）

画面説明清掃イベント実施中の経過時間と、スマートフォンセンサーから取得した活動量をリアルタイムに可視化する画面。
デモ動作条件活動時間（00:12:34）、歩数（1842歩）、距離（1.24km）、カロリー（56kcal）がカウントアップし、回収ゴミの数に王道デモ用の「5個」が入力された状態。
外部APIの除外サードパーティ製地図APIの統合に伴うインフラコスト、従量課金、キー秘匿要件を回避するため、地図コンポーネントはフェーズ2へ戦略的に除外。
遷移・バックエンド「活動を終了する」ボタン押下 ➔ 確定したゴミ数「5個」をPOSTリクエストで送信し、04 イベント終了・活動結果へ遷移。

SCREEN 04

イベント終了・活動結果

画面説明清掃アクティビティ完了時の成果提示画面。バックエンドで算出された確定エコインセンティブと運動実績をリザルト表示。
デモ動作条件前画面から安全に引き継がれたデータに基づき、獲得インセンティブが＋100 pt（ゴミ5個×10pt=50pt ＋ イベント固有ボーナス50pt）と明示された状態。
整合性の担保Flaskのコントローラー（`event_finish`）からテンプレートへ変数を動的バインディングし、設計上の期待値と1ミリのズレもない同期を完了。
遷移・バックエンド「トップメニューへ戻る」ボタン押下 ➔ ユーザーのポイントを加算更新（インクリメント）し、05 トップメニュー（反映後）へ遷移。
